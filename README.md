## Описание

Система предназначена для ведения учёта компьютерного и офисного оборудования в образовательных учреждениях. Позволяет структурировать данные по зданиям, кабинетам, типам оборудования и единицам оборудования с их характеристиками.

**Особенности:**
- Трёхуровневая архитектура (БД → API → Клиент)
- Ролевая модель доступа
- Гибкая система характеристик оборудования

---

## Функциональность

- Аутентификация и авторизация пользователей (JWT)
- Управление зданиями (CRUD)
- Управление кабинетами (CRUD)
- Управление типами оборудования (CRUD)
- Управление оборудованием с характеристиками (CRUD)
- Поиск и фильтрация оборудования
- Ролевой доступ (Admin, Operator, Viewer)

## Установка и запуск

### 1. База данных

Установите Microsoft SQL Server и выполните скрипты в порядке нумерации:

```sql
Файлы/БД/01_CreateTables.sql    -- создание таблиц
Файлы/БД/02_InsertData.sql      -- наполнение тестовыми данными (1000+ записей)
```

### 2. Запуск API

```bash
cd Файлы/API/SchoolEquipmentApi
dotnet restore
dotnet run
```

API запустится на `https://localhost:5001` и `http://localhost:5000`

### 3. Настройка клиента

В файле `SchoolEquipmentApp/Services/ApiService.cs` укажите URL вашего API:

```csharp
private string _baseUrl = "https://localhost:5001/api/";
```

### 4. Запуск клиента

Откройте `SchoolEquipmentApp.sln` в Visual Studio и запустите проект.

## Структура базы данных

### Схема

```
Buildings (1) ──► (M) Classrooms (1) ──► (M) Equipment (M) ──► (M) EquipmentSpecifications
                    │                              │
                    │                              │
                    ▼                              ▼
              EquipmentTypes (1) ──► (M) SpecificationCategories
```

### Таблицы

| Таблица | Описание |
|---------|----------|
| `Buildings` | Здания школы |
| `Classrooms` | Кабинеты (привязка к зданию) |
| `EquipmentTypes` | Типы оборудования (PC, Printer, Projector...) |
| `Equipment` | Единицы оборудования (инв. номер, модель, статус...) |
| `SpecificationCategories` | Категории характеристик (CPU, RAM, HDD...) |
| `EquipmentSpecifications` | Характеристики оборудования (значения) |
| `Users` | Пользователи системы |
