# Учёт компьютерного оборудования в школе

Программный комплекс, разработанный в рамках производственной практики по модулю ПМ.02 «Осуществление интеграции программных модулей».

## 📋 Описание проекта

Система предназначена для автоматизации учёта компьютерного и офисного оборудования в школе. Позволяет вести учёт зданий, кабинетов, типов оборудования и единиц оборудования с их характеристиками.

## ⚙️ Функциональность

- Регистрация и вход пользователей (Admin, Operator, Viewer)
- Управление зданиями (CRUD)
- Управление кабинетами (CRUD)
- Управление типами оборудования (CRUD)
- Управление оборудованием с характеристиками (CRUD)

- Ролевой доступ (Admin, Operator, Viewer)

## 🔧 Установка и запуск

### 1. Развертывание базы данных

Установите Microsoft SQL Server 2019/2022 и выполните скрипты:

```sql
-- Создание таблиц
01_CreateTables.sql

-- Наполнение демоданными (1000+ записей)
02_InsertData.sql
```

### 2. Запуск API

```bash
cd Файлы/API/SchoolEquipmentApi
dotnet restore
dotnet run
```

API будет доступен по адресу: `https://localhost:5001`

### 3. Настройка клиента

В файле `SchoolEquipmentApp/Services/ApiService.cs` укажите URL вашего API:

```csharp
private string _baseUrl = "https://localhost:5001/api/";
```

### 4. Запуск клиента

Откройте решение `SchoolEquipmentApp.sln` в Visual Studio и запустите проект.
